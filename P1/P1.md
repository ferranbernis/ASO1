<h2>Script</h2>

<h3>1. Configuració inicial i preparació de la xarxaVariables globals:</h3>

<p>Defineix la ruta de l'informe (/tmp/informe_sistema.txt), el port web (8000), el destinatari del correu i les credencials d'autenticació per a Gmail mitjançant una contrasenya d'aplicació.   Tallafocs (UFW): Obre el port 8000/TCP si l'eina ufw està instal·lada al sistema.   Detecció d'IP: Executa un bucle d'espera (fins a 30 reintents) que comprova cada segon si la màquina ha obtingut una adreça IP vàlida diferent de 127.0.0.1.</p>
   
<h3>2. Servidor web HTTPS</h3>
   
<p>s'ubica al directori /tmp i arrenca un servidor web integrat de Python (python3 -m http.server 8000) en segon pla (&).   Això permet que qualsevol fitxer creat a /tmp (com l'informe) sigui accessible a través d'un navegador web consultant la IP de la màquina al port 8000.</p>

   
<h3>3. Generació de l'informe (generar_informe)</h3>
<p>Aquesta funció recopila informació detallada del sistema operatiu i maquinari en un format estructurat i ho guarda a /tmp/informe_sistema.txt amb permisos de lectura (chmod 644):   Sistema operatiu i hipervisor: Identifica la distribució (/etc/os-release), versió del nucli, arquitectura, entorn virtualitzat (systemd-detect-virt) i el temps d'activitat (uptime).   CPU i GPU: Extrau el model del processador (/proc/cpuinfo o lscpu), nombre de nuclis assignats (nproc) i la targeta gràfica (lspci).   Memòria RAM i Emmagatzematge: Mostra el total i la RAM disponible (free -h), així com l'ús de disc per a fitxers del sistema com ext4, xfs, etc. (df -h).   Xarxa i Ports: Obté el hostname, la llista d'adreces IP locals i els serveis que estan escoltant en ports oberts (ss -tulpn).   Programari: Llista els primers 100 paquets Debian/APT instal·lats (dpkg-query) i les aplicacions Snap presents.</p>
   
<h3>4. Configuració de correu i enviament (msmtp)</h3>
<p>Fitxer de configuració temporal: Genera un fitxer /tmp/msmtp_informe.conf amb permissos restringits (chmod 600) per connectar-se de manera segura mitjançant TLS al servidor SMTP de Gmail (smtp.gmail.com:587).   Enviament únic: Envia un missatge de correu amb el contingut de l'informe adjunt en el cos del text utilitzant l'eina msmtp. Si no està instal·lada, mostra un avís d'error per consola amb l'ordre d'instal·lació necessària.</p>
  
<h3>5. Bucle d'actualització contínua</h3>
<p>Una vegada enviat el primer correu, el script entra en un bucle infinit (while true).   Cada 30 segons torna a executar la funció generar_informe per sobreescriure el fitxer /tmp/informe_sistema.txt amb les dades actualitzades en temps real, mantenint la informació al dia per a qui hi accedeixi via web.</p>
